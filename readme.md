# Features

- User Daily Task
- Daily Progress
- Task Completed
- Focus Time
- Focus Timer
- Calender
- Mark Assignments According To The Desired Date
- Insight
- Daily completion 
- Today Progress
- Note Focus Time Today
- Saw Tasks Planned Today
- Note Completion Rate
- Creation Streak every day
- Can See This Week, This Month, Even Years
- Appereance Choose Theme Dark Or Light Mode

## Instalation

### 1. Clone Repository

```bash
git clone https://github.com/Muhhanifsr/FocusFlowApp.git
cd FocusFlowApp
```

## 2. Install Depedencies

```bash
npm install
```

## 3. Configure Environtment Variables

create a .env file :

```bash
VITE_GOOGLE_SHEETS_WEB_APP_URL=your_link_appscript
```

## 4. Run The Application

```bash
npm run dev
```
